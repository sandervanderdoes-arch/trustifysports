# trustifysports.com

Source of the Trustify Sports website. Built with React, Vite, TypeScript and Tailwind,
published to GitHub Pages from `main` by `.github/workflows/deploy-site.yml`.

```sh
npm ci
npm run dev      # http://localhost:8080
npm test
npm run build    # output in dist/
```

See `CLAUDE.md` for how the site is maintained, the contact-form setup and the copy rules.
